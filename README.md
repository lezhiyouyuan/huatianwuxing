# 1. 整理说明

《华天五星》，全名《神道大编·象宗·华天五星》，〔明〕周述学 撰，是中华星学经典书籍之一。

在已有文本（「踏歌独行」在微信公众号「虚中之行」发布；「闲鹤」提供；[识典古籍](https://www.shidianguji.com/book/CADAL02093863})）的基础上，对照参考版本，逐字逐句点校，并以 LaTeX 重排，制作适于阅读、检索、存档与引用的 PDF 版本，即《神道大编·象宗·华天五星》精校本。

参考版本：《续修四库全书·子部·天文算法类》第 1031 册《神道大编·象宗·华天五星》。

因古籍版本影印，整理中或有异文、讹字及录入疏漏，敬请联系： lezhiyouyuan@gmail.com 。

# 3. 前言

星学复兴，始于正本；古法重明，必先正籍。

《明史》载，周述学著有《神道⼤编》千余卷。然今存《续修四库全书·⼦部》三册，共四十二卷：

- 第 1031 册《神道⼤编·象宗·华天五星》九卷
- 第 1036 册《神道⼤编·历宗·通议》⼗八卷
- 第 1043 册 《神道⼤编·历宗·算会》⼗五卷

《神道⼤编》其他宗包括：图书、皇极、律吕、山经、水志、分野、舆地、算法、太乙、壬遁、演禽、风角、鸟占、兵符、阵法、卦影、禄命、建除、葬术、五运六气、海道针经。留待后人，有缘得阅。今本《邵子神数》亦由《神道大编》而出。

特集《明史·周述学》《黄梨洲文集·周云渊先生传》《国朝献征录·山阴云渊周子述学传》于前，以飨读者。
